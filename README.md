# PoserGive (Fabric 1.21.4)

Клиентский аддон для Armor Poser (8.1.2+), добавляющий:
- поиск по всем зарегистрированным предметам (включая предметы других модов);
- категории;
- поле NBT/компонентов **без ограничения длины**;
- поле количества предметов;
- отправку выбранного предмета в руку стойки через сетевой мост Armor Poser.

## Управление
- Горячая клавиша по умолчанию: `P`.
- Кнопка `PoserGive` автоматически добавляется в экраны Armor Poser (через mixin).

## Конфиг
`config/posergive.json`
```json
{
  "openPickerKey": 80,
  "blacklist": [
    "minecraft:command_block"
  ]
}
```

## Сборка
```bash
gradle build
```

> В текущей среде CI может не быть доступа к репозиторию Fabric Maven.
