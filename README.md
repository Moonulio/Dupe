# PoserGive (Fabric 1.21.4)

Клиентский аддон для Armor Poser (8.1.2+), использующий **raw CompoundTag**,
который отправляется C2S-пакетом в формате `SyncData(UUID, CompoundTag)` на серверный обработчик Armor Poser (не в публичный чат).

## Что умеет
- поиск по всем зарегистрированным предметам (включая предметы других модов);
- категории;
- редактирование количества предмета;
- поле NBT/компонентов **без ограничения длины**;
- поле raw CompoundTag **без ограничения длины**;
- креатив-подобная сетка выбора предмета с иконками и кликом;
- генерация шаблона `HandItems` и ручное редактирование перед отправкой;
- проверка доступности сетевого канала `armorposer:sync_data` перед отправкой (чтобы не ловить disconnect).

## Управление
- Горячая клавиша по умолчанию: `P`.
- Кнопка `PoserGive` автоматически добавляется в экраны Armor Poser (через mixin).

## Конфиг
`config/posergive.json`
```json
{
  "openPickerKey": 80,
  "blacklist": [
    "minecraft:command_block"
  ]
}
```

## Сборка
```bash
gradle build
```
